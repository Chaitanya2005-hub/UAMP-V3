# 🚀 Get Shit Done (GSD) Execution Engine

The **Get Shit Done (GSD)** skill is an aggressive, high-velocity autonomous execution framework designed to drive complex coding goals to 100% verified completion without stopping prematurely or asking for trivial user input.

---

## 📋 Core Operating Directives

1. **Relentless Ownership**:
   - Do not stop halfway through a feature or request.
   - Do not stop after editing a single file — build, run, test, and verify the full feature.

2. **Goal Decomposition Protocol**:
   - Break large goals into a clear task list:
     - 📍 **Step 1: Code Discovery & Context Analysis**
     - 📍 **Step 2: Concrete Implementation**
     - 📍 **Step 3: Automated Verification (Build / Test / Runtime Check)**
     - 📍 **Step 4: Quality Polish & Completion Report**

3. **No Stopping on Transient Errors**:
   - If a command or build fails, read the log immediately, fix the root cause, re-run, and verify.
   - Continue until all tasks are marked as complete and verified.
